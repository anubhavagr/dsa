## ✏️ Phase 2 — One-page design (25 min)
- [ ] API / interface sketch
  - route(origin, dest, depart_time, options) → {polyline, ETA, legs}; rerouteCheck(position, route_id) → keep/new route
- [ ] Data model + storage choice justified out loud
  - Road graph = directed edges with turn restrictions, partitioned into tiles; traffic as per-edge weight overlays — graph and traffic are separate stores, say why
- [ ] Box-and-arrow diagram — every box gets a one-line reason
  - Keep it ≤8 boxes; past that, group boxes and name the groups
- [ ] Graph preprocessing: contraction hierarchies / hub labels — say what gets precomputed and what query time buys
  - Say the trade in one line: weeks of preprocessing buys millionths of the graph per query
- [ ] Regional tiling: planet partitioned into regions; cross-region routes stitch at border nodes
- [ ] Traffic as edge-weight overlays: historical (predictive, precomputed) + live (probe/fleet updates, minutes stale — SAY the staleness number)
- [ ] ETA model: routing time + ML correction for reality (lights, turns, human behavior)
- [ ] Rerouting loop: client sends position deltas; server re-evaluates when ETA degradation crosses a threshold
- [ ] Scaling story: partition key chosen + hot spots named
  - Partition by region tile; hot spots = metro rush hours and one crashed region — say both
- [ ] Failure story: what's lost on crash, replication, honest CAP position
  - Traffic overlay lost → fall back to historical weights (worse ETA, still routes); graph store lost → region dark — different severity, say so

## 📖 Phase 4 — Reference checkpoints (open only AFTER your attempt)
What a strong L5 answer includes:
- Road graph = directed edges with turn restrictions — modeled as a graph problem from minute one
- Preprocessing: contraction hierarchies / hub labels → ~ms queries after O(weeks) of preprocessing — you SAY the tradeoff
  - Say it: "Contraction hierarchies precompute shortcut edges over unimportant nodes — weeks of preprocessing, milliseconds per query."
- ALT (A* with landmark-triangle distances) named as the middle option between plain A* and full CH
  - Say it: "ALT is the middle option — landmark triangle distances guide A* without full preprocessing."
- Regions/tiles partition the planet; cross-region routes stitch at border nodes
- Traffic = per-edge overlay: historical (predictive, precomputed) + live (probe/fleet updates, minutes stale — staleness number stated)
  - Say it: "Live traffic is minutes stale, historical is predictive — the ETA model knows which is which."
- ETA = routing time + ML correction model — the graph alone is systematically wrong, say why
  - Say it: "Routing time is systematically optimistic — an ML correction layer closes the gap to reality."
- Reroute = client position deltas + server re-evaluation when ETA degradation crosses a threshold — cheaper than continuous recompute
  - Say it: "Re-route when ETA degradation crosses a threshold — event-driven, not a per-second recompute per driver."
- Geocoding (text → lat/lng) is a SEPARATE system — say the boundary
  - Say it: "Geocoding is a separate system — text in, coordinates out; this design starts at coordinates."
- Offline: phone caches tiles + last route + a local graph — degradation ordered and defended: live traffic goes first, then re-routing, map tiles last
