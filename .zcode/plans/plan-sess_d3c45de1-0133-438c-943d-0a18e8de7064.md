## 4. Dashboard & tracking

**README.md** — hero stats auto-updated by `tracker.py` between `<!-- TRACKER:BEGIN -->` markers: overall % complete (day + problem counts), per-phase progress bars, per-week table (13 rows × 7 date links), struggle-count "redo queue" summary, current week highlight.

**tracker.py** (stdlib only) — run `python3 tracker.py` any time: walks `days/*.md`, counts checked vs unchecked problem boxes and concepts, regenerates the stats block in README, prints a one-line summary. Day status derives purely from checkboxes — no manual bookkeeping.
