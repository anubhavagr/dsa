## 🔥 Pattern of the Day: States on Nodes — (take, skip) + Null Markers
Serialization: preorder *with an explicit marker for every empty slot* is lossless — the markers pin down exactly where each subtree ends, so deserialization consumes one stream in the same order and rebuilds the shape with no lookahead.
Tree DP: each node returns one small tuple of states; the parent combines children's states under the problem's constraint (can't rob two adjacent levels). Count-good-nodes is the third flavor: a single value (path max) rides *down* instead of up.

- **Reach for it when:** a constraint couples a node with its parent or children (you cannot rob two adjacent levels) — express it either as states returned upward from each subtree or as context passed downward from the root.
- **Key invariant:** The serializer and the deserializer must traverse in exactly the same order — preorder with every null-child marker included — or the rebuilt tree will not match the original.
- **Watch out:** Forgetting to emit a marker for null children makes the serialized string ambiguous — different trees then serialize to the same string, so deserialization can rebuild the wrong shape.
- **How to say it in an interview:** "For serialization I write a preorder traversal with an explicit marker for every empty child slot, which pins down exactly where each subtree ends; deserialization then just consumes the same stream in the same order with no lookahead. For the tree DP, each node passes its information upward as one small tuple of states — take this node or skip it — and the parent combines the children's states under the problem's constraint."
- **Test with:** an empty tree (its serialization is the single marker "#") · a single node · an all-negative-values tree for the robbery DP (the best plan is to rob nothing, so the answer is 0).
- **Complexity:** Serialization and deserialization each take O(n), because every node and every null marker is written or read exactly once; the tree DP is O(n) with the two states (take, skip) computed once per node.

```python
def serialize(root):                      # preorder + '#' pins empty slots
    if root is None:
        return '#,'
    return f"{root.val}," + serialize(root.left) + serialize(root.right)

def deserialize(data):                    # consume the SAME stream, preorder
    vals = iter(data.split(','))
    def build():
        v = next(vals)
        if v == '#': return None
        n = TreeNode(int(v)); n.left = build(); n.right = build()
        return n
    return build()

def rob(root):                            # LC 337: two states per node
    def states(n):
        if n is None:
            return 0, 0                   # (rob_this, skip_this)
        L, R = states(n.left), states(n.right)
        return (n.val + L[1] + R[1],      # rob it: children must skip
                max(L) + max(R))          # skip it: children free
    return max(states(root))
```
