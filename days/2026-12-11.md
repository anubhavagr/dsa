## 🔥 Pattern of the Day: Model first, traverse second
Google hands you data that isn't a graph and waits to see if you make it one: a matrix is a DAG of increasing steps, a set of equations is a weighted graph, a bus network is a graph over *routes*, not stops. Step one is always the modeling decision — say out loud what a node is and what an edge costs. Only then pick the traversal: DFS with memo when revisits can't help, BFS by layers when a level means "one more move".

```python
from functools import lru_cache

def longest_increasing_path(grid: list[list[int]]) -> int:
    # Strictly increasing steps => no cycles => a cell's answer is final
    # once computed. The memo turns path explosion into O(rows*cols).
    rows, cols = len(grid), len(grid[0])

    @lru_cache(maxsize=None)
    def dfs(r: int, c: int) -> int:
        best = 1
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if (0 <= nr < rows and 0 <= nc < cols
                    and grid[nr][nc] > grid[r][c]):   # invariant: step up
                best = max(best, 1 + dfs(nr, nc))
        return best

    return max(dfs(r, c) for r in range(rows) for c in range(cols))
```
