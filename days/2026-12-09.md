## 🔥 Pattern of the Day: The O(n) set-membership streak scan
A hash set answers in O(1) the questions that sorting only answers after O(n log n) work. The non-obvious move in the streak scan: only start counting from numbers that *begin* a run — `n − 1 not in set` — so every element is touched at most twice and the whole thing stays linear. The same "ask the map about the prefix" reflex solves both subarray problems the moment you switch to remainders.

```python
def longest_streak(nums: list[int]) -> int:
    # Only streak STARTS do work: n is a start iff n-1 is absent.
    seen = set(nums)
    best = 0
    for n in seen:
        if n - 1 in seen:
            continue                  # invariant: each streak is walked exactly
        length = 1                    # once — from its smallest member
        while n + length in seen:
            length += 1
        best = max(best, length)
    return best
```
