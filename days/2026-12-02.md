## 🔥 Pattern of the Day: XOR Toolkit — Cancellation, Lowest Bit, Carries
Three identities do almost all the work. (1) x ^ x = 0 and x ^ 0 = x, and XOR is
commutative and associative — so folding an array cancels pairs and leaves the
unpaired element, order irrelevant. (2) n & (n-1) clears the lowest set bit
(subtracting one borrows through the trailing zeros and flips that bit), which
counts set bits in as many steps as there are bits, and also answers "is n a power
of two" in one operation. (3) Binary addition decomposes: a ^ b is the sum without
carries, (a & b) << 1 is exactly the carries — loop until the carry stream dies.
Python quirk to volunteer in interviews: ints are unbounded, so emulate the 32-bit
word with a mask and translate the final bit pattern back to a signed value.

```python
def single_number(nums: list[int]) -> int:
    x = 0
    for n in nums:
        x ^= n          # pairs annihilate: a^a = 0; order never matters
    return x

def count_bits_in(n: int) -> int:
    bits = 0
    while n:             # n & (n-1) drops the lowest set bit in one operation
        n &= n - 1       # e.g. 12 (1100) -> 8 (1000): 1100 & 1011 = 1000
        bits += 1
    return bits

def get_sum(a: int, b: int) -> int:
    mask = 0xFFFFFFFF                     # work inside a 32-bit word
    while b & mask:                       # b is the outstanding carries
        a, b = (a ^ b) & mask, ((a & b) << 1) & mask
    return a if a <= 0x7FFFFFFF else ~(a ^ mask)   # re-sign if bit 31 is set
```

**Worked example** — adding 6 + 3 without `+` (carry loop):

| step | a = partial sum | b = carries |
|---|---|---|
| 0 | 0110 (6) | 0011 (3) |
| 1 | 0101 (5) = 6^3 | 0100 (4) = (6&3)<<1 |
| 2 | 0001 (1) = 5^4 | 1000 (8) = (5&4)<<1 |
| 3 | 1001 (9) = 1^8 | 0000 — done |

Same three lines would add 4-bit or 40-bit numbers; the loop length is set by how
far carries propagate, worst case one per bit position.
