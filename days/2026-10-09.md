## 🔥 Pattern of the Day: Expand around center
Every palindrome has a center: a character (odd length) or a gap between characters (even length) — 2n − 1 centers in total.
From each center, grow outward while the ends mirror; every palindrome your loop touches is discovered exactly once, giving O(n²) time and O(1) space with no DP table.
Reach for it on "longest palindromic substring" and friends; reach for a plain two-pointer equality scan when you only need to TEST palindromicity.
Invariant: when the expansion stops, the last matching window [l+1, r−1] is the maximal palindrome for that center.
Complexity to narrate: (2n − 1) centers × O(n) expansion = O(n²) time, O(1) space — and the DP alternative is also O(n²) time but pays O(n²) space, which is why nobody asks for it.
Say the center count derivation out loud: n character centers plus n − 1 gap centers — missing the gaps is the most common wrong answer in this family.
For parsing, enumerate states before code: leading whitespace, optional sign, the digit run, the first non-digit — each state has one rule, and each rule has one test case.
Strings are immutable in Python — every slice is a copy; say that cost when you write s[i:j], because the interviewer will.
When asked "can you do better?": O(n) palindrome algorithms exist (Manacher's) — name it, then say you would ship expand-around-center under interview time pressure.

```python
def longest_palindrome_brute(s):       # O(n^3): every substring, rescan
    best = ""
    for i in range(len(s)):
        for j in range(i, len(s)):
            sub = s[i:j + 1]
            if sub == sub[::-1] and len(sub) > len(best):
                best = sub
    return best
```

```python
def longest_palindrome(s):
    def span(l, r):                    # grow outward while it stays a mirror
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l, r = l - 1, r + 1
        return s[l + 1:r]              # last valid window after overshoot

    best = ""
    # every palindrome is discovered from its center exactly once
    for i in range(len(s)):
        for cand in (span(i, i),       # odd center: character i
                     span(i, i + 1)):  # even center: gap after i
            if len(cand) > len(best):
                best = cand
    return best
```

Watch-outs:
- 2n − 1 centers, not n — forgetting the even (gap) centers silently drops answers like "abba".
- Parsing problems (atoi) are state machines, not cleverness: enumerate the states (whitespace, sign, digits, overflow) before writing a line, then test each edge by hand.
- Interviews probe parsing edge cases deliberately — leading zeros, "+-12", "  42", "0032", overflow past 2³¹−1: have an example ready for each.
- Near-miss palindromes ("abca"), single characters, and the empty string are the cheap tests — run all three before submitting any palindrome code.
