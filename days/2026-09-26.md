## 🔥 Pattern of the Day: Trade memory for time
The brute-force instinct is a nested loop: for each element, scan all the others.
A hash map deletes the inner scan — as you walk the array once, remember what you have seen, and ask the map the exact question the inner loop was asking, in O(1) instead of O(n).
That single trade — space for time — powers more interview solutions than any other move, and it is the backbone of every Arrays & Hashing day this week.
Invariant: after processing index i, `seen` holds every value from the prefix you could still need — you never look back at raw elements again.
Say costs out loud as you code ("this is n-squared; I am deleting the inner loop") — that narration is exactly what a senior interviewer scores.

| Code shape | Time complexity | What it means and when to use it |
|---|---|---|
| One loop over the input, constant work per element | O(n) | The default target for array problems. Doubling the input doubles the work. |
| Nested loops that compare all pairs | O(n²) | At n = 10,000 this is 100 million steps — usually too slow. Remove the inner loop with a hash map, or restructure using sorted order. |
| Hash map / set lookup inside a single loop | O(n) average | The map answers "have I seen x before?" in constant time, replacing the inner loop entirely. You pay for the speed with extra memory. |
| Sort first, then scan with two pointers | O(n log n) | Sorting costs more than one scan, but it creates the order that lets you find pairs with a single linear pass instead of checking every combination. |
| Binary search over sorted data | O(log n) | Each comparison discards half of the remaining candidates: 1,000,000 sorted items are searched in about 20 steps. |

```python
def two_sum_brute(nums, target):       # the O(n^2) instinct, for contrast
    n = len(nums)
    for i in range(n):
        for j in range(i + 1, n):      # this inner scan is what the map deletes
            if nums[i] + nums[j] == target:
                return [i, j]
    return []

def two_sum(nums, target):
    seen = {}                          # value -> index of an earlier occurrence
    for i, x in enumerate(nums):       # one pass; seen covers nums[:i] exactly
        if target - x in seen:         # the O(1) version of the inner scan
            return [seen[target - x], i]
        seen[x] = i                    # insert AFTER checking — no self-pairing
    return []
```

Watch-out: a hash map answers "have I seen x?" — it cannot answer "where is the nearest x to my left?" Know which question you are asking before you reach for one.
