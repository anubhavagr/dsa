## 🔥 Pattern of the Day: Grid Flood Fill — Mark on Entry
A grid is a graph you never build: neighbors come from four fixed offsets, and bounds checks replace adjacency lists.
DFS explores one connected blob, marking cells as it *enters* them — the mark is the visited set, so no cell recurses twice (mark on exit = infinite loop). BFS explores in rings: everything at distance d+1 is one layer past distance d, which is why unweighted shortest path is exactly BFS.

- **Reach for it when:** the input is a matrix and the operation is flood fill, counting regions, measuring a region's area, or finding an unweighted shortest path.
- **Key invariant:** A cell is marked visited at the instant it is enqueued (BFS) or entered (DFS), never when it is later dequeued — marking late lets the same cell enter the structure multiple times.
- **Watch out:** Overwriting the grid values as your visited set is a legitimate O(1)-extra-memory trick, but announce it out loud ("I will mutate the input — is that acceptable?") because silently destroying the caller's data is a real cost.
- **How to say it in an interview:** "I mark each cell as visited the moment I enter or enqueue it — not when I pop it — so no cell is ever processed twice; marking on exit instead makes the traversal loop forever. And in BFS, each cell's distance from the source is simply the layer number of the frontier wave in which it is first reached, which is why BFS is exactly shortest path on unweighted grids."
- **Test with:** an all-water grid (zero islands to find) · a 1×1 grid · two land blobs that touch only at a diagonal corner (under 4-way adjacency they are separate regions).
- **Complexity:** The traversal is O(m·n) because each of the m·n cells is marked on entry and therefore enters the stack or queue at most once.

```python
from collections import deque

DIRS = ((1, 0), (-1, 0), (0, 1), (0, -1))

def flood_fill(img, sr, sc, color):       # DFS marks as it goes
    old = img[sr][sc]
    if old == color: return img           # else we'd repaint forever
    def dfs(r, c):
        if 0 <= r < len(img) and 0 <= c < len(img[0]) and img[r][c] == old:
            img[r][c] = color             # mark ON ENTRY, not on exit
            for dr, dc in DIRS: dfs(r + dr, c + dc)
    dfs(sr, sc); return img

def steps_away(grid, start):              # BFS: distance = layer number
    q, seen, dist = deque([start]), {start}, 0
    while q:
        for _ in range(len(q)):           # one full layer per outer pass
            r, c = q.popleft()
            for dr, dc in DIRS:
                nr, nc = r + dr, c + dc
                if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]) and (nr, nc) not in seen:
                    seen.add((nr, nc))    # mark when ENQUEUED
                    q.append((nr, nc))
        dist += 1
    return dist
```
