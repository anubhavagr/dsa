## 🔥 Pattern of the Day: Root from Preorder, Split from Inorder
Preorder's first unread element is always the next root to create; inorder tells you which nodes belong to that root's left subtree — everything left of its index.
So construction consumes preorder through an iterator (roots arrive top-down) and recurses on inorder *ranges* picked out by an index map, never slicing lists. General LCA on an unordered tree works the opposite direction: each node reports whether p or q lives below it, and the first node that sees one on each side is the answer.

- **Reach for it when:** a problem hands you traversal output and asks you to rebuild the tree, or asks for a common ancestor on a tree that lacks the BST property.
- **Key invariant:** At every recursive call, the not-yet-consumed preorder elements and the current inorder range describe exactly the same set of pending nodes.
- **Watch out:** Build the left subtree before the right one — the preorder iterator must be consumed in exactly root-left-right order, and swapping the two recursive calls silently builds a different, wrong tree.
- **How to say it in an interview:** "The first unread element of the preorder list is always the next root to create. Its position in the inorder list then splits that list into exactly the nodes of the root's left subtree (everything before the position) and its right subtree (everything after), so I recurse on ranges of the inorder list while consuming preorder through one iterator."
- **Test with:** a single-node tree · duplicate values (the preorder+inorder build assumes values are distinct — confirm that constraint) · a tree that is one left-going chain, plus an LCA query where p is an ancestor of q.
- **Complexity:** Building the tree is O(n) when a hash map gives each value's inorder index in O(1) — O(n²) if you slice sublists instead, because each slice copies — and the general LCA traversal is O(n) since every node is visited once.

```python
def build_tree(preorder, inorder):
    idx = {v: i for i, v in enumerate(inorder)}   # O(1) root lookup
    pre = iter(preorder)                          # roots arrive top-down
    def build(lo, hi):                            # inorder[lo:hi] is ours
        if lo == hi:
            return None                           # empty range, no node
        node = TreeNode(next(pre))                # take the next root
        mid = idx[node.val]                       # inorder splits on it
        node.left = build(lo, mid)                # left range FIRST
        node.right = build(mid + 1, hi)
        return node
    return build(0, len(inorder))

def lca(root, p, q):                      # general (unordered) tree
    if root in (None, p, q):
        return root                       # found a target (or nothing)
    L, R = lca(root.left, p, q), lca(root.right, p, q)
    return root if L and R else L or R    # both sides -> root; else bubble up
```
