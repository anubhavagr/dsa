## 🔥 Pattern of the Day: Level-by-level pointer chaining
Trees at Meta come in two flavors: traverse by level, and split by midpoint. The next-pointer problem rewards you for noticing you can chain level N+1 *while walking* level N — each parent already knows its neighbors, so no queue and O(1) extra space. The sorted-list-to-BST problem is your old slow-fast midpoint reflex plus one discipline: sever the list at the middle so the two recursions can't touch each other.

```python
def connect(root: "Node") -> None:
    # Chain the next level while walking the current one:
    # each node wires its own children, then hands the baton right.
    if not root:
        return
    leftmost = root
    while leftmost.left:              # invariant: `leftmost` starts each level
        head = leftmost
        while head:
            head.left.next = head.right          # siblings
            if head.next:
                head.right.next = head.next.left # cousins
            head = head.next
        leftmost = leftmost.left
```
