## 🔥 Pattern of the Day: Prefix Tree with Dict Nodes
A trie shares prefixes: inserting costs O(word length), and "is this prefix live?" is a walk, not a scan.
Make the node a dict subclass so `node[ch]` is the child edge, and carry one boolean — `end` — which is what distinguishes a stored word from a prefix that merely passes through. Wildcard search turns one deterministic walk into a DFS that forks at every '.'.

- **Reach for it when:** many strings are stored and the queries are about prefixes, or when a board search must try every word of a shared dictionary (the trie prunes dead prefixes early).
- **Key invariant:** A node's `end` flag being true means a stored word terminates exactly at this node — it says nothing about whether children exist below, and a node can have either property without the other.
- **Watch out:** search and startsWith walk the trie identically and differ only in the final check — search requires the end-of-word flag on the last node, startsWith only requires the path to exist — so state out loud which of the two you are implementing.
- **How to say it in an interview:** "I make each trie node a dict that maps a character to its child node, so following a word is a sequence of dict lookups rather than a scan of all strings. Each node carries one boolean that is true exactly when a stored word ends there — that flag is what distinguishes a complete word from a prefix that merely passes through."
- **Test with:** the empty string · a query equal to a stored word's prefix but not the word itself, like "app" when "apple" is stored (startsWith is true, search is false) · an all-dots wildcard query like "..." (must match every stored word of that length).
- **Complexity:** Insert and plain search cost O(L) for a word of length L; each '.' in a wildcard query forks up to 26 branches, and a board search over the whole dictionary is exponential in the worst case, though trie pruning cuts it down heavily in practice.

```python
class TrieNode(dict):                     # a node IS its children map
    def __init__(self):
        self.end = False                  # a stored word terminates here

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        n = self.root
        for ch in word:
            n = n.setdefault(ch, TrieNode())   # descend, creating as needed
        n.end = True

    def search(self, word):               # '.' = wildcard in this variant
        def dfs(i, node):
            if i == len(word):
                return node.end           # must be a WORD, not a prefix
            ch = word[i]
            if ch == '.':                 # fork over EVERY child
                return any(dfs(i + 1, c) for c in node.values())
            return ch in node and dfs(i + 1, node[ch])
        return dfs(0, self.root)
```
