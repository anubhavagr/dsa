## 🔥 Pattern of the Day: The index stack
When a problem is about matching or evaluating pairs — brackets, operators, nested scopes — push the *index* (the position) onto the stack, not the value. The position is what you need the moment something fails to match: which paren to delete, which operand to collapse. Calculator evaluation and invalid-paren marking are the same machine in different clothes, and Meta asks both to see whether you see that.

```python
def unmatched_indices(s: str) -> set[int]:
    # Stack holds indices, never chars — the position is the payload.
    # When a match fails, you need WHERE, not what.
    stack: list[int] = []
    marked: set[int] = set()
    for i, ch in enumerate(s):
        if ch == "(":
            stack.append(i)
        elif ch == ")":
            if stack:
                stack.pop()          # invariant: stack top = last unmatched "("
            else:
                marked.add(i)        # closer with no opener
    marked.update(stack)             # leftovers = openers with no closer
    return marked                    # keep everything NOT in this set
```
