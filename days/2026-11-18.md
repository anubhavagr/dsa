## 🔥 Pattern of the Day: Amount DP + Patience Tails
Coin change: `dp[a]` = fewest coins for amount a; each coin offers `dp[a-c] + 1` — reuse is free because the state indexes amounts, not remaining coins.
LIS in O(n log n): `tails[i]` = smallest possible tail of any increasing subsequence of length i+1. The array stays sorted, so `bisect_left` finds where each x either extends the longest run or lowers an existing tail — the length is always right even though tails isn't the subsequence itself.

- **Reach for it when:** "make amount X with unlimited pieces" or "longest increasing run".
- **Key invariant:** tails is sorted; dp[a] only reads strictly smaller amounts.
- **Watch out:** dp dimension over amounts with `inf` = unreachable — don't conflate with 0.
- **Interview soundbite:** "Amounts index the state; tails keep the best ends."
- **Test out loud:** amount 0 · a coin larger than the amount · an impossible amount · empty nums for LIS.
- **Cost:** coin change O(amount × coins); LIS O(n log n).

```python
from bisect import bisect_left

def coin_change(coins, amount):           # unbounded: coins reusable
    dp = [0] + [float('inf')] * amount    # dp[a]: fewest coins for a
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a:
                dp[a] = min(dp[a], dp[a - c] + 1)
    return dp[amount] if dp[amount] < float('inf') else -1

def lis(nums):                            # tails[i]: best tail of length i+1
    tails = []
    for x in nums:
        i = bisect_left(tails, x)         # first tail >= x
        if i == len(tails):
            tails.append(x)               # x extends the longest run
        else:
            tails[i] = x                  # smaller tail for length i+1
    return len(tails)
```
