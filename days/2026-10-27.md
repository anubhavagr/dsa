## 🔥 Pattern of the Day: Post-Order Tree DP — Return (depth, best)
A node can hand its parent only a *straight leg* — one downward path that continues upward — but the *best full answer* may bend at the node itself, joining both children's legs.
So every subtree returns two numbers: `depth` (the leg the parent is allowed to reuse) and `best` (a finished answer that never extends further). Maximum depth, diameter, and balance are all this template with a different combine step.

- **Reach for it when:** the answer at each node can be computed from the answers of its children — maximum depth, diameter, and balance checks are all instances of this template.
- **Key invariant:** The `depth` a node returns is only ever consumed by its parent to build longer downward paths, while `best` is a finished answer that no node above is allowed to extend.
- **Watch out:** Decide up front whether you are counting edges or nodes and state it out loud — mixing the two mid-solution makes a reported depth or diameter off by one.
- **How to say it in an interview:** "Each node returns two values to its parent: the longest downward path starting at this node, and the best answer found anywhere in this subtree. Only the first may be extended by the parent, because a path through both children already turns at this node and cannot grow upward."
- **Test with:** a single node · a one-sided chain of 5 nodes (its diameter equals its height: 4 edges) · an empty tree.
- **Complexity:** O(n) time — each node is visited exactly once, so no memoization is needed — and O(h) recursion stack space, where h is the tree height.

```python
def postorder_dp(root):
    """Every node returns (depth, best) to its parent."""
    if root is None:
        return 0, 0                       # depth feeds the parent; best is done
    ld, lb = postorder_dp(root.left)
    rd, rb = postorder_dp(root.right)
    depth = 1 + max(ld, rd)               # the straight leg extends upward
    best = max(lb, rb, ld + rd)           # the answer that BENDS at this node
    return depth, best

def diameterOfBinaryTree(root):           # LC 543: longest path, in edges
    return postorder_dp(root)[1]

def isBalanced(root):                     # LC 110: sentinel = early exit
    def depth(n):
        if n is None:
            return 0
        L, R = depth(n.left), depth(n.right)
        if L < 0 or R < 0 or abs(L - R) > 1:
            return -1                     # -1 poisons every ancestor
        return 1 + max(L, R)
    return depth(root) >= 0
```
