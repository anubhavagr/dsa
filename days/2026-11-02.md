## 🔥 Pattern of the Day: Size-k Min-Heap
For "k largest of n", keep the k best-so-far in a MIN-heap: the root is the weakest survivor, so each new element costs one comparison — beat the root and it enters (evicting the root), else it's discarded.
That is O(n log k) time and O(k) space, which matters when n streams past you or is huge. Python's heapq is a min-heap only; fake a max-heap by pushing negated values.

- **Reach for it when:** "k largest / k closest / k most frequent" — especially over a stream.
- **Key invariant:** heap size never exceeds k, so `heap[0]` is the current k-th best.
- **Watch out:** min-heap for k *largest* (not max-heap) — the weakest survivor must sit at the root.
- **Interview soundbite:** "The weakest of the k best sits at the root — that's the k-th."
- **Test out loud:** k = n · duplicates everywhere · a stream that only ever raises the bar.
- **Cost:** O(n log k) time and O(k) space, versus O(n log n) to sort everything.

```python
import heapq

def top_k(nums, k):                       # k largest, O(n log k), O(k) space
    heap = nums[:k]                       # candidate survivors
    heapq.heapify(heap)                   # MIN-heap: root = weakest survivor
    for x in nums[k:]:
        if x > heap[0]:                   # beats the weakest?
            heapq.heapreplace(heap, x)    # evict it, admit x
    return sorted(heap, reverse=True)

class KthLargest:                         # LC 703: streaming version
    def __init__(self, k, nums):
        self.k, self.h = k, nums
        heapq.heapify(self.h)
        while len(self.h) > self.k:       # shrink to the k best seen
            heapq.heappop(self.h)
    def add(self, val):
        heapq.heappush(self.h, val)
        if len(self.h) > self.k:
            heapq.heappop(self.h)         # invariant: len(h) == k
        return self.h[0]                  # weakest of the k best = k-th

def k_closest(points, k):                 # LC 973: squared distance keys
    return heapq.nsmallest(k, points, key=lambda p: p[0]**2 + p[1]**2)
```
