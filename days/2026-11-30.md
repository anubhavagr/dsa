## 🔥 Pattern of the Day: The * Consumes or Skips
dp[i][j] asks: does s[:i] match p[:j]? Ordinary characters and '.' are the easy
case — consume one from each side, read the diagonal. All the difficulty lives in
'*', which always has a companion (regex: the char before it; wildcard: nothing)
and always offers exactly two futures: match zero occurrences (skip, reading
dp[i][j-2] in regex form) or absorb one more character of s (reading dp[i-1][j],
gated on the companion matching s[i-1]). A two-way OR of already-solved cells is
the signature of this whole family. Two details interviews probe: the empty-string
row dp[0][j] is not all False — leading "x*x*x*" patterns can match "" — and the
two problems differ in whether '*'s companion exists at all. Recite the invariant:
**when computing dp[i][j], every strictly smaller prefix pair is already final.**

```python
def is_match(s: str, p: str) -> bool:
    m, n = len(s), len(p)
    dp = [[False] * (n + 1) for _ in range(m + 1)]   # dp[i][j]: does s[:i] match p[:j]?
    dp[0][0] = True
    for j in range(1, n + 1):                        # seed: empty s vs pattern prefixes
        if p[j - 1] == '*':
            dp[0][j] = dp[0][j - 2]                  # "x*" may match zero characters
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            c = p[j - 1]
            if c == '*':
                dp[i][j] = dp[i][j - 2] or (          # skip: '*' matches nothing
                    dp[i - 1][j] and p[j - 2] in (s[i - 1], '.'))  # consume one more s-char
            elif c == '.' or c == s[i - 1]:
                dp[i][j] = dp[i - 1][j - 1]           # single-char match consumes both
    return dp[m][n]
```

The fork, isolated (this is the line to be able to write from memory):

| dp[i][j] facing `x*` | reads | meaning |
|---|---|---|
| skip branch | dp[i][j-2] | star matches zero copies of x |
| consume branch | dp[i-1][j], if x ∈ {s[i-1], '.'} | star absorbs s[i-1] and stays available |

**Worked example** — `s = "aab"`, `p = "c*a*b"` (expected True). Final table:

| s \ p | "" | c | c* | c*a | c*a* | c*a*b |
|---|---|---|---|---|---|---|
| **""** | T | F | T | F | T | F |
| **a** | F | F | F | T | T | F |
| **aa** | F | F | F | F | T | F |
| **aab** | F | F | F | F | F | T |

Read the corner: bottom-right T. Note row "" — "c*" and "c*a*" match empty (skip
branch), but "c*a" does not: skipping can delete pattern, never the string.
