## 🔥 Pattern of the Day: Two Heaps Around the Middle
Keep the smaller half in a max-heap (negated values) and the larger half in a min-heap. Two invariants make the median readable in O(1): every element of `lo` ≤ every element of `hi`, and the sizes differ by at most one.
Insert routes through one heap into the other — push to `hi`, move `hi`'s smallest into `lo` — so the ordering invariant repairs itself, then a single move rebalances the sizes. The median is the top of the bigger half (odd count) or the average of both tops.

- **Reach for it when:** a stream asks for a middle statistic, or two halves must answer a question jointly.
- **Key invariant:** all(lo) ≤ all(hi), and |len(lo) − len(hi)| ≤ 1.
- **Watch out:** forgetting the negation on the max-heap half silently corrupts ordering.
- **Interview soundbite:** "Two halves, two flavors, one rebalance."
- **Test out loud:** two elements (parity flips) · a pre-sorted stream · negative values.
- **Cost:** add O(log n), median O(1); the heaps hold every element once — O(n) space.

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.lo = []                      # max-heap (negated): smaller half
        self.hi = []                      # min-heap: larger half

    def addNum(self, x):
        heapq.heappush(self.lo, -heapq.heappushpop(self.hi, x))  # route via hi
        if len(self.lo) > len(self.hi) + 1:      # keep |lo|-|hi| <= 1
            heapq.heappush(self.hi, -heapq.heappop(self.lo))

    def findMedian(self):
        if len(self.lo) > len(self.hi):   # odd: lo holds the extra
            return -self.lo[0]
        return (-self.lo[0] + self.hi[0]) / 2

def k_smallest_pairs(a, b, k):            # frontier heap: advance j only
    h = [(a[i] + b[0], i, 0) for i in a[:k]]
    heapq.heapify(h)                      # each a[i]'s best partner is b[0]
    out = []
    while h and len(out) < k:
        _, i, j = heapq.heappop(h); out.append([a[i], b[j]])
        if j + 1 < len(b): heapq.heappush(h, (a[i] + b[j + 1], i, j + 1))
    return out
```
