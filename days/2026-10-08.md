## 🔥 Pattern of the Day: Prefix sums + a map of what came before
A prefix array turns any range sum into one subtraction; combined with a hash map of earlier prefix values, it turns "count subarrays with sum k" into a lookup.
The algebra to internalize: sum(i..j) = P[j] − P[i−1], so "subarray with sum k ending at j" means "an earlier prefix equal to P[j] − k" — hunt prefixes, not subarrays.
Reach for prefix sums on repeated range queries or any counting-over-subarrays question; reach for Kadane when the object is the best single subarray.
Invariant: after step j, the map contains every prefix value from index < j — only then is the count honest.

```python
class NumArray:                          # O(n) per query — the trap version
    def __init__(self, nums):
        self.nums = nums
    def sumRange(self, left, right):
        return sum(self.nums[left:right + 1])
```

```python
class NumArray:                          # O(n) once, then O(1) per query
    def __init__(self, nums):
        self.P = [0]                     # P[i] = sum of nums[:i]
        for x in nums:
            self.P.append(self.P[-1] + x)
    def sumRange(self, left, right):
        return self.P[right + 1] - self.P[left]   # the whole trick

def subarray_sum(nums, k):
    count = {0: 1}                       # empty prefix has sum 0 — the seed
    prefix = hits = 0
    for x in nums:
        prefix += x
        hits += count.get(prefix - k, 0) # earlier prefixes worth prefix-k
        count[prefix] = count.get(prefix, 0) + 1   # add AFTER counting
    return hits

def kadane(nums):
    best = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)            # extend the run, or restart at x
        best = max(best, cur)
    return best
```

Watch-outs:
- The {0: 1} seed is what counts subarrays that start at index 0 — forget it and every answer comes out short.
- Update the map after querying it, or a subarray can pair with itself.
- Kadane's `max(x, cur + x)` decision is the entire algorithm — be ready to say why a negative running best can never pay off later.
