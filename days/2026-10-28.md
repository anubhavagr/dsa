## 🔥 Pattern of the Day: Tightening Bounds & the Sorted Walk
The BST property constrains every ancestor, so each recursive call carries an open interval (lo, hi): a node is legal iff its value lands inside, and each child gets a tightened interval — left tightens hi, right tightens lo.
An inorder walk emits values in sorted order, so a generator turns the tree into a lazy sorted stream you can stop at the k-th element. For LCA, orderedness means a single comparison at the root tells you which subtree to descend (or that you are standing on the answer).

- **Reach for it when:** the problem says BST — never re-derive sortedness, use it.
- **Key invariant:** every value in a subtree must sit strictly inside (lo, hi).
- **Watch out:** comparing a node only to its immediate children passes the naive test and fails LeetCode's.
- **Interview soundbite:** "The interval narrows at every turn; an inorder walk reads the tree sorted."
- **Test out loud:** the classic [5,4,6,null,null,3,7] trap · duplicates (strict or not — ask!) · k = 1 and k = n.
- **Cost:** validate is O(n) time / O(h) space; kth with early stop is O(h + k).

```python
def is_valid_bst(root, lo=float('-inf'), hi=float('inf')):
    # invariant: EVERY value in this subtree must land in (lo, hi)
    if root is None:
        return True
    if not lo < root.val < hi:
        return False
    return (is_valid_bst(root.left, lo, root.val) and   # left tightens hi
            is_valid_bst(root.right, root.val, hi))     # right tightens lo

def inorder(root):                        # a BST walks out SORTED
    if root:
        yield from inorder(root.left)
        yield root.val
        yield from inorder(root.right)

def kth_smallest(root, k):                # stop at the k-th yield
    for i, val in enumerate(inorder(root), 1):
        if i == k:
            return val

def lca_bst(root, p, q):                  # ordered: one comparison per step
    while root:
        if p.val < root.val > q.val: root = root.left      # both small
        elif p.val > root.val < q.val: root = root.right   # both large
        else: return root                 # split point = the answer
```
