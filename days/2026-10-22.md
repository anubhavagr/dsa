## 🔥 Pattern of the Day: Partition, don't sort
Selection ("kth largest") does not need order — it needs one element in its final sorted position, which is exactly what a partition delivers.
Quickselect runs the partition and recurses into ONE side (average O(n), worst O(n²) — randomize the pivot), skipping the other entirely; that skip is the entire speedup over sorting.
With many duplicates, two-way partitions degrade — a three-way (Dutch flag) partition splits into <, =, > zones and makes equal-to-pivot blocks free.
Reach for partitioning on kth-order statistics, and for Dutch-flag structure whenever a problem names exactly three classes (0/1/2, negatives/zeros/positives).
Invariant (Dutch flag): [lo, lt) is all-smaller, [lt, i) is all-equal, (gt, hi] is all-greater, [i, gt] is unexamined.

```python
def sort_colors(a):                    # Dutch flag: one pass, O(1) space
    lt, i, gt = 0, 0, len(a) - 1
    while i <= gt:
        if a[i] == 0:
            a[lt], a[i] = a[i], a[lt]  # ship a 0 to the front zone
            lt += 1
            i += 1
        elif a[i] == 2:
            a[i], a[gt] = a[gt], a[i]  # ship a 2 to the back zone — the new
            gt -= 1                    # a[i] is UNEXAMINED, so i does NOT move
        else:
            i += 1                     # a 1 stays in the middle zone
```

```python
from random import randint

def kth_largest(a, k):                 # k = 1 -> the maximum; average O(n)
    k = len(a) - k                     # target index in ascending order
    lo, hi = 0, len(a) - 1
    while True:
        p = a[randint(lo, hi)]         # random pivot: worst case fades away
        lt, i, gt = lo, lo, hi         # Dutch-flag partition around p
        while i <= gt:                 # [lo,lt) < p · [lt,i) == p · (gt,hi] > p
            if a[i] < p:
                a[lt], a[i] = a[i], a[lt]
                lt += 1
                i += 1
            elif a[i] > p:
                a[i], a[gt] = a[gt], a[i]
                gt -= 1
            else:
                i += 1
        if k < lt:                     # target lives in the < zone
            hi = lt - 1
        elif k > gt:                   # target lives in the > zone
            lo = gt + 1
        else:
            return p                   # k sits inside the == zone: done
```

Watch-outs:
- After swapping with the back zone, do not advance i — the incoming element is unexamined; that one line is the whole Dutch-flag interview.
- A heap (size k, O(n log k)) is the alternative for kth largest — mention it, then show quickselect when the interviewer asks for average O(n).
- Merge intervals: sorting by start makes "overlaps current" a single comparison against the running end — state that before coding it.
