## 🔥 Pattern of the Day: Design the State, Then the Loops
The hard part of DP is not the loops; it is the state definition. Word break wants `dp[i]` = "prefix s[:i] can be segmented", which makes the recurrence a scan over the LAST word's split point.
Decode ways counts with zero-guards: some states must be forcibly 0. Longest string chain orders states so dependencies compute first (shorter words first) and each state checks its delete-one predecessors. The question to burn in: *what prefix does dp[i] describe, and what was the last choice?*

- **Reach for it when:** a sequence problem resists a two-term recurrence — the state is probably richer than an index.
- **Key invariant:** every state is computable from strictly "smaller" states (shorter prefix, shorter word, earlier index).
- **Watch out:** processing order must respect that smaller-ness — sort when the relation isn't positional.
- **Interview soundbite:** "What prefix does dp[i] describe, and what was the last choice?"
- **Test out loud:** s = "" · a word longer than s · "06" and "10" in decode · duplicate words.
- **Cost:** word break O(n²·L); string chain O(N·L²).

```python
def word_break(s, word_dict):             # dp[i]: s[:i] is segmentable
    words = set(word_dict)
    dp = [True] + [False] * len(s)
    for i in range(1, len(s) + 1):        # prefix grows rightward
        for j in range(i):                # try every LAST word s[j:i]
            if dp[j] and s[j:i] in words:
                dp[i] = True
                break                     # one witness suffices
    return dp[-1]

def longest_chain(words):                 # LC 1048: states by length
    best = {}                             # word -> longest chain ending there
    for w in sorted(words, key=len):      # predecessors are always shorter
        preds = (w[:i] + w[i + 1:] for i in range(len(w)))  # delete one
        best[w] = 1 + max((best.get(p, 0) for p in preds), default=0)
    return max(best.values(), default=0)

def decode_count(s):                      # LC 91: two-term count, zero-guards
    prev2, prev1 = 1, 0 if s[:1] == '0' else 1   # ways(0), ways(1)
    for i in range(2, len(s) + 1):
        cur = prev1 if s[i - 1] != '0' else 0    # one-digit reading
        if s[i - 2] != '0' and int(s[i - 2:i]) <= 26:
            cur += prev2                         # two-digit reading is legal
        prev2, prev1 = prev1, cur
    return prev1 if s else 0
```
