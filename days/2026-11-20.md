## 🔥 Pattern of the Day: Design the State, Then the Loops
The hard part of DP is not the loops; it is the state definition. Word break wants `dp[i]` = "prefix s[:i] can be segmented", which makes the recurrence a scan over the LAST word's split point.
Decode ways counts with zero-guards: some states must be forcibly 0. Longest string chain orders states so dependencies compute first (shorter words first) and each state checks its delete-one predecessors. The question to burn in: *what prefix does dp[i] describe, and what was the last choice?*

- **Reach for it when:** a sequence problem resists a simple two-term recurrence — that is the signal the state needs to be richer than a bare index, such as "the prefix s[:i] is segmentable" instead of "the best value ending at i".
- **Key invariant:** Every state must be computable from strictly "smaller" states — a shorter prefix, a shorter word, an earlier index — so the dependency graph has no cycles and some fill order can finish it.
- **Watch out:** The processing order must compute every state before anything that depends on it — when the dependency is not positional (a shorter word precedes its delete-one extensions), sort by length first, or a state reads an uninitialized value and returns garbage.
- **How to say it in an interview:** "The hard part of a DP is not the loops, it is the state definition — so before writing any loop I answer two questions out loud: what exactly does dp[i] say about the prefix ending at i, and what was the last choice that produced it? For word break, dp[i] means 'the prefix s[:i] can be fully segmented into dictionary words', and the last choice is the final word's split point, which turns the recurrence into a scan over split points."
- **Test with:** the empty string s = "" · a dictionary word longer than s (it can never match) · the strings "06" and "10" for decode ways (a leading zero forces the count to 0, while "10" decodes as the single letter J) · duplicate words in the input list (must not double-count or crash).
- **Complexity:** Word break tries every split point for every prefix and hashes words of length up to L, giving O(n²·L); longest string chain checks each of N words' delete-one predecessors over words of length L, giving O(N·L²).

```python
def word_break(s, word_dict):             # dp[i]: s[:i] is segmentable
    words = set(word_dict)
    dp = [True] + [False] * len(s)
    for i in range(1, len(s) + 1):        # prefix grows rightward
        for j in range(i):                # try every LAST word s[j:i]
            if dp[j] and s[j:i] in words:
                dp[i] = True
                break                     # one witness suffices
    return dp[-1]

def longest_chain(words):                 # LC 1048: states by length
    best = {}                             # word -> longest chain ending there
    for w in sorted(words, key=len):      # predecessors are always shorter
        preds = (w[:i] + w[i + 1:] for i in range(len(w)))  # delete one
        best[w] = 1 + max((best.get(p, 0) for p in preds), default=0)
    return max(best.values(), default=0)

def decode_count(s):                      # LC 91: two-term count, zero-guards
    prev2, prev1 = 1, 0 if s[:1] == '0' else 1   # ways(0), ways(1)
    for i in range(2, len(s) + 1):
        cur = prev1 if s[i - 1] != '0' else 0    # one-digit reading
        if s[i - 2] != '0' and int(s[i - 2:i]) <= 26:
            cur += prev2                         # two-digit reading is legal
        prev2, prev1 = prev1, cur
    return prev1 if s else 0
```
