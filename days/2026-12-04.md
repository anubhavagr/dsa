## 🔥 Pattern of the Day: Prefix-Sum Sampling & Fisher–Yates
Weighted choice in O(log n) per draw: lay the weights end to end as a running
(prefix) sum — a number line cut into segments whose lengths are the weights. One
uniform integer in [1, total] lands in exactly one segment; binary search finds
the first prefix ≥ the draw. Segment length = weight = probability mass, which is
the whole proof of correctness, said in one sentence. Fisher–Yates shuffles in
place and is uniform because of a counting argument: going backwards, slot i is
filled by a uniform choice among the i + 1 not-yet-finalized elements, so the run
produces n × (n-1) × … × 1 equally likely outcomes — exactly n!, no overcounting.
The classic bug is drawing j from the full range every time, which makes some
permutations reachable in more ways than others. Reach for these whenever a
problem says "random", "uniform", or "with probability proportional to".

```python
import random
from bisect import bisect_left
from itertools import accumulate

class WeightedPick:
    def __init__(self, w: list[int]):
        self.prefix = list(accumulate(w))     # segment boundaries on the number line

    def pick_index(self) -> int:
        r = random.randint(1, self.prefix[-1])   # uniform over [1, total]
        return bisect_left(self.prefix, r)       # first boundary >= r = chosen segment

def shuffle(nums: list[int]) -> None:
    for i in range(len(nums) - 1, 0, -1):    # Fisher-Yates: fill from the back
        j = random.randint(0, i)             # j from the UNSHUFFLED prefix [0..i] only
        nums[i], nums[j] = nums[j], nums[i]  # slot i is now finalized forever
```

**Worked example A — weighted pick**, `w = [1, 3]` → `prefix = [1, 4]`:

| draw r (uniform in [1..4]) | bisect_left | index | probability |
|---|---|---|---|
| 1 | 0 | 0 | 1/4 |
| 2, 3, 4 | 1 | 1 | 3/4 |

**Worked example B — Fisher–Yates** on `[a, b, c]`:

| step i | eligible j | outcomes |
|---|---|---|
| 2 | {0, 1, 2} | 3 choices — which element lands in the last slot |
| 1 | {0, 1} | 2 choices for the middle |

3 × 2 × 1 = 6 = 3! equally likely permutations; slot 0 gets whatever remains.
