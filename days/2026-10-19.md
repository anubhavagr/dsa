## 🔥 Pattern of the Day: Include/exclude with a start index
Every subset is a sequence of binary answers — "is element i in, or out?" — so the recursion tree has 2ⁿ leaves and each leaf IS a subset; collect them at the leaves or on the way down.
A start index (not "every element, anywhere") enforces non-decreasing positions, which makes combinations instead of permutations — one parameter, entirely different tree.
Duplicates break the tree's uniqueness; the repair is sort first, then when you EXCLUDE a value, exclude all its copies at once — a run of identical branches collapses into one.
Reach for it on subsets, combinations, and any "choose some elements" enumeration.
Invariant: the path plus the untouched suffix completely describes the state — nothing else is needed, so nothing else is stored.

```python
def subsets(nums):                     # the clean 2^n tree, no duplicates
    out = []
    def backtrack(i, path):
        if i == len(nums):
            out.append(path[:])        # a leaf: one complete subset
            return
        backtrack(i + 1, path)         # EXCLUDE nums[i]
        path.append(nums[i])           # INCLUDE nums[i]
        backtrack(i + 1, path)
        path.pop()                     # un-choose (leaves path reusable)
    backtrack(0, [])
    return out
```

```python
def subsets_with_dup(nums):
    nums.sort()                        # duplicates become adjacent — required
    out = []
    def backtrack(i, path):
        if i == len(nums):
            out.append(path[:])
            return
        path.append(nums[i])           # INCLUDE nums[i]
        backtrack(i + 1, path)
        path.pop()
        j = i + 1                     # EXCLUDE: skip EVERY copy of nums[i],
        while j < len(nums) and nums[j] == nums[i]:
            j += 1                    # or identical subsets print twice
        backtrack(j, path)
    backtrack(0, [])
    return out
```

Watch-outs:
- `path[:]` at the leaf, never `path` — appending the live list stores an alias that mutates under you.
- The dedup skip belongs on the EXCLUDE branch: taking one copy then skipping the rest generates every distinct subset exactly once.
- Combination problems allow reuse by recursing with the same i, not i + 1 — one character of difference, entirely different tree; know which the problem wants.
