## 🔥 Pattern of the Day: Old → New Map (+ Invert the Question)
Cloning a graph with cycles: keep a dict from original node to its clone — that map IS the visited set. Register the clone *before* recursing into neighbors, or a cycle double-creates nodes.
The same inversion instinct handles regions: "enclosed" is painful to test directly, but "escapes to the border" is easy — walk inward from every border cell, mark what you reach as safe, and everything unmarked is capturable. Pacific-Atlantic is the same trick twice: start at each ocean and walk uphill.

- **Reach for it when:** a question asks "which regions/cells can reach X" — flip it to "what does X reach".
- **Key invariant:** `copies[n]` exists before any neighbor of n is visited.
- **Watch out:** cloning the node but sharing neighbor lists — deep copy means new edge objects too.
- **Interview soundbite:** "Register the clone before recursing; solve the complement, not the question."
- **Test out loud:** single node · a two-node cycle · an all-border region of O's.
- **Cost:** O(V + E); the old→new map doubles as memo and visited set.

```python
def cloneGraph(node):                     # old -> new map IS the visited set
    if node is None:
        return None
    copies = {}

    def dfs(n):
        if n in copies:                   # seen before: return its clone
            return copies[n]              #   (this is what breaks cycles)
        copies[n] = Node(n.val)           # register BEFORE recursing
        copies[n].neighbors = [dfs(m) for m in n.neighbors]
        return copies[n]

    return dfs(node)

def reaches(grid, starts):                # reverse the flow: walk UPHILL
    R, C = len(grid), len(grid[0])
    seen, stack = set(starts), list(starts)
    while stack:                          # from ocean cells inward
        r, c = stack.pop()
        for nr, nc in ((r+1,c), (r-1,c), (r,c+1), (r,c-1)):
            if (0 <= nr < R and 0 <= nc < C and (nr, nc) not in seen
                    and grid[nr][nc] >= grid[r][c]):   # uphill reaches us
                seen.add((nr, nc))
                stack.append((nr, nc))
    return seen                           # intersect two oceans for the answer
```
