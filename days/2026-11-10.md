## 🔥 Pattern of the Day: Old → New Map (+ Invert the Question)
Cloning a graph with cycles: keep a dict from original node to its clone — that map IS the visited set. Register the clone *before* recursing into neighbors, or a cycle double-creates nodes.
The same inversion instinct handles regions: "enclosed" is painful to test directly, but "escapes to the border" is easy — walk inward from every border cell, mark what you reach as safe, and everything unmarked is capturable. Pacific-Atlantic is the same trick twice: start at each ocean and walk uphill.

- **Reach for it when:** a question asks which regions or cells can reach a target — flip the direction and ask what the target can reach, which usually turns many traversals into one.
- **Key invariant:** The clone of node n exists in the `copies` map before any neighbor of n is visited — that ordering is what breaks cycles.
- **Watch out:** A deep copy needs new neighbor relationships, not just new nodes — if the clone's neighbor list still points into the original graph, the two objects share state and mutations leak between them.
- **How to say it in an interview:** "To clone a graph that may contain cycles, I keep a dict from each original node to its clone, and that dict is also my visited set. The key rule is to register a node's clone before recursing into its neighbors, so when a cycle comes back to this node I find the existing clone instead of creating a second one. For the regions problem I use the same inversion instinct: 'enclosed' is hard to test directly, but 'escapes to the border' is easy — I walk inward from every border cell, mark what I reach as safe, and everything unmarked is capturable."
- **Test with:** a single node with no neighbors · a two-node cycle (exercises the register-before-recursing rule) · a region of O's that touches the border (it escapes, so it must not be captured).
- **Complexity:** The clone runs in O(V + E) time — each node and each edge is handled exactly once — and the original-to-clone dict doubles as the visited set, so no separate structure is needed.

```python
def cloneGraph(node):                     # old -> new map IS the visited set
    if node is None:
        return None
    copies = {}

    def dfs(n):
        if n in copies:                   # seen before: return its clone
            return copies[n]              #   (this is what breaks cycles)
        copies[n] = Node(n.val)           # register BEFORE recursing
        copies[n].neighbors = [dfs(m) for m in n.neighbors]
        return copies[n]

    return dfs(node)

def reaches(grid, starts):                # reverse the flow: walk UPHILL
    R, C = len(grid), len(grid[0])
    seen, stack = set(starts), list(starts)
    while stack:                          # from ocean cells inward
        r, c = stack.pop()
        for nr, nc in ((r+1,c), (r-1,c), (r,c+1), (r,c-1)):
            if (0 <= nr < R and 0 <= nc < C and (nr, nc) not in seen
                    and grid[nr][nc] >= grid[r][c]):   # uphill reaches us
                seen.add((nr, nc))
                stack.append((nr, nc))
    return seen                           # intersect two oceans for the answer
```
