## 🔥 Pattern of the Day: One Wave from Every Source
Running BFS once per source is O(sources × cells). Instead, seed the queue with ALL sources at distance 0 and let a single wave expand: because the frontier is the union of every circle, the first time any cell is reached is by its NEAREST source.
Whenever a problem says "time until the nearest X reaches everything" or "distance to closest Y", this is the move. Word Ladder adds the implicit-graph twist: nodes are words, and neighbors come from wildcard patterns (`h*t`) rather than pairwise comparison.

- **Reach for it when:** many origin cells all spread at once and you need the distance to the nearest origin at every cell — rotting oranges, nearest zero, nearest exit.
- **Key invariant:** Each cell's distance is written exactly once, at the moment the cell is first reached from the frontier — in BFS the first arrival is always via a shortest path, so that single write is already the optimal value.
- **Watch out:** Seed every source at distance 0, not 1 — starting at 1 shifts every reported distance by one — and handle the empty-source case explicitly, returning -1 (or whatever the problem specifies) rather than crashing or returning 0.
- **How to say it in an interview:** "Instead of running one BFS per source, which costs O(sources × cells), I put every source in the queue at distance 0 and let a single wave expand. Because the frontier is the union of the circles around all sources, the first time any cell is reached is necessarily from its nearest source — so one traversal computes every cell's distance to its closest source."
- **Test with:** an empty source list (nothing spreads; return -1 if the answer is a maximum distance) · a grid where every cell is a source (all distances are 0) · a pocket of cells no wave can reach (their distances stay unset).
- **Complexity:** The grid is traversed once, O(m·n), because all sources share a single wave — instead of O(sources × m·n) for a separate BFS from each source.

```python
from collections import deque

def nearest_source(grid, is_source):      # one wave from ALL sources
    R, C = len(grid), len(grid[0])
    q, dist = deque(), {}
    for r in range(R):                    # seed EVERY source at distance 0
        for c in range(C):
            if is_source(grid[r][c]):
                q.append((r, c)); dist[(r, c)] = 0
    while q:
        r, c = q.popleft()
        for nr, nc in ((r+1,c), (r-1,c), (r,c+1), (r,c-1)):
            if 0 <= nr < R and 0 <= nc < C and (nr, nc) not in dist:
                dist[(nr, nc)] = dist[(r, c)] + 1   # FIRST reach = NEAREST
                q.append((nr, nc))
    return dist

def rot_minutes(grid):                    # LC 994: layers = minutes
    dist = nearest_source(grid, lambda v: v == 2)     # rotten = sources
    fresh = {(r, c) for r in range(len(grid))
             for c in range(len(grid[0])) if grid[r][c] == 1}
    if any(f not in dist for f in fresh):
        return -1                         # a fresh orange never got reached
    return max(dist.values(), default=0)
```
