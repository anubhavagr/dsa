Palindromes are the friendliest interval DP: dp[i][j] depends only on the pair (i, j) and the interval strictly inside. The lesson of the day is loop order — length first, start second — because "inside" must already be solved when "outside" asks about it.

## 🔥 Pattern of the Day: Gap / Interval DP — Length, Then Start
A substring's palindrome-ness has exactly two inputs: do its ends match, and is the
inside a palindrome. That self-reference forces the fill order: every interval of
length L is computed before any interval of length L+1, so the outer loop is LENGTH
and the inner loop is START. The base cases fall out free — lengths 1 and 2 have no
(or empty) inside. Reach for this whenever a decision about a range depends on
sub-ranges: palindromes, matrix-chain-style merging, partition costs. The invariant
to recite: when computing dp[i][j], dp[i+1][j-1] is already final. For longest
palindromic subsequence (not substring) the recurrence is LCS-flavored — ends match:
2 + inside; ends differ: max of dropping either end — same loop order still.

```python
def longest_palindrome(s: str) -> str:
    n = len(s)
    # dp[i][j] = True if s[i..j] is a palindrome — filled by LENGTH, then start
    dp = [[False] * n for _ in range(n)]
    best = (0, 0)
    for length in range(1, n + 1):           # outer: interval LENGTH — inside-out
        for i in range(0, n - length + 1):   # inner: start index
            j = i + length - 1
            if s[i] == s[j] and (length <= 2 or dp[i + 1][j - 1]):
                dp[i][j] = True              # ends match AND the inside is already solved
                if length > best[1] - best[0] + 1:
                    best = (i, j)
    return s[best[0]:best[1] + 1]
```

**Worked example** — `s = "babad"`, every interval classified:

| length | intervals checked | palindromes |
|---|---|---|
| 1 | b, a, b, a, d | all 5 (single chars) |
| 2 | ba, ab, ba, ad | none |
| 3 | bab, aba, bad | bab, aba |
| 4 | baba, abad | none |
| 5 | babad | none |

Best length 3 → "bab" (first found) or "aba" — both accepted. Notice row 3 needed
row 1 (the empty inside of length-3 intervals is a length-1 fact) and row 4 needed
row 2 — which is exactly why length is the outer loop.

Self-check before the problems:
- For length 2, why does the code never consult dp[i+1][j-1] — what is the "inside" there?
- The full string "babad" fails before its inside is ever read — which condition gates that, and why?
