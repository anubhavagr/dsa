## 🔥 Pattern of the Day: One Skeleton, Three Slots
Every recursive traversal is the same shape — go left, go right, and decide *where the work happens*: before the children (pre), between them (in), or after (post).
The choice is dictated by dependencies: need children's answers first → post-order; building top-down → pre-order; BST sortedness → in-order. Iteration replaces the call stack with an explicit stack whose invariant is "ancestors still awaiting their turn." BFS is a different animal: the queue holds exactly one level.

- **Reach for it when:** any problem says tree + "visit / collect / level / view".
- **Key invariant:** stack = nodes owed a visit; BFS queue = exactly one level.
- **Watch out:** marking visited at the wrong moment (entry vs exit) = infinite loops.
- **Interview soundbite:** "Same skeleton, three slots — the dependency decides where the work goes."
- **Test out loud:** empty tree · single node · a left-skewed chain (stack depth) · a complete tree (queue width).
- **Cost:** O(n) time for every order; space is O(h) for the stack vs O(w) for the level queue.

```python
from collections import deque

def traverse(n, slot):                    # one skeleton, three orders
    if n is None:
        return []
    L, R = traverse(n.left, slot), traverse(n.right, slot)
    return {'pre': [n.val, *L, *R], 'in': [*L, n.val, *R], 'post': [*L, *R, n.val]}[slot]

def inorder_iter(root):                   # explicit stack replaces recursion
    out, st, n = [], [], root
    while n or st:                        # invariant: st = nodes owed a visit
        while n:
            st.append(n); n = n.left      # slide left, saving the path
        n = st.pop()                      # leftmost unvisited node
        out.append(n.val); n = n.right    # in-order visit, then right subtree
    return out

def levels(root):                         # BFS: queue holds exactly one level
    out, q = [], deque([root] if root else [])
    while q:
        out.append([])                    # the level we are draining now
        for _ in range(len(q)):           # snapshot BEFORE enqueueing children
            n = q.popleft(); out[-1].append(n.val)
            q.extend(c for c in (n.left, n.right) if c)
    return out
```
