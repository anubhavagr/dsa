## 🔥 Pattern of the Day: Union-Find — Compress & Rank
Union-Find answers "are these two in the same set?" *incrementally*, as edges arrive — something DFS must redo from scratch.
`find` walks to the root, then path-compression re-hangs every node it passed so the next find is nearly flat. `union` attaches one root under the other by rank to keep trees shallow, and returns False when the endpoints were already connected — which is precisely a "redundant edge" or "cycle just formed" signal. Together the two optimizations give amortized near-constant time.

- **Reach for it when:** edges arrive over time / you only need connectivity, not paths.
- **Key invariant:** one root per component; the root is the component's name.
- **Watch out:** unioning nodes instead of roots — the #1 implementation bug.
- **Interview soundbite:** "One root per component — union roots, never nodes."
- **Test out loud:** unioning an already-connected pair · find on a fresh node · a long union chain (depth stays tiny).
- **Cost:** amortized α(n) ≈ constant per op with compression + rank; O(n) space.

```python
class UF:
    def __init__(self, n):
        self.parent = list(range(n))      # everyone starts alone
        self.rank = [0] * n               # union by rank keeps trees flat

    def find(self, x):
        root = x
        while self.parent[root] != root:  # walk up to the root
            root = self.parent[root]
        while self.parent[x] != root:     # path compression: re-hang all
            self.parent[x], x = root, self.parent[x]
        return root

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False                  # already connected (edge redundant)
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra               # attach the shorter under taller
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True
```
