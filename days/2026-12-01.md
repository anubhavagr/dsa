## 🔥 Pattern of the Day: State Machines & Interval DP
State-machine DP: name states by what you are ALLOWED to do next (rest, hold, sold),
make forbidden transitions impossible by construction, and update all three from
yesterday's values simultaneously — in Python, a single tuple assignment, otherwise
you'd compute "sold" from the "rest" you overwrote two lines earlier. Product
subarrays use the same trick in miniature: carry the best AND worst product ending
here, because a negative flips their roles. Interval DP for burst balloons: think
about which balloon in an interval is burst LAST — its coin value is then fixed by
the interval's ORIGINAL walls, and the two sides become independent subproblems.
That reversal (last, not first) is the entire difficulty of the problem.

```python
import math
from functools import lru_cache

def max_profit_cooldown(prices: list[int]) -> int:
    rest, hold, sold = 0, -math.inf, -math.inf   # best profit per state, after today's close
    for p in prices:
        rest, hold, sold = (max(rest, sold),     # did nothing (or finished cooling)
                            max(hold, rest - p), # keep holding, or buy while in rest
                            hold + p)            # sell — one tuple = all read yesterday's row
    return max(rest, sold)

def max_coins(nums: list[int]) -> int:
    a = [1, *nums, 1]                             # sentinel walls outside the array
    @lru_cache(None)
    def pop(l, r):                                # best from bursting everything strictly inside (l, r)
        return max((a[l] * a[k] * a[r] + pop(l, k) + pop(k, r)
                    for k in range(l + 1, r)), default=0)   # k = balloon burst LAST here
    return pop(0, len(a) - 1)
```

**Worked example** — cooldown states for `prices = [1, 2, 3, 0, 2]` (answer 3):

| day (price) | rest | hold | sold |
|---|---|---|---|
| 0 (1) | 0 | -1 | -inf |
| 1 (2) | 0 | -1 | 1 |
| 2 (3) | 1 | -1 | 2 |
| 3 (0) | 2 | 1 | -1 |
| 4 (2) | 2 | 1 | 3 |

Read the path off the table: buy day 0, sell day 1 (+1), forced rest, buy day 3,
sell day 4 (+2) → 3. Also note day 3: hold improves to 1 by buying the 0 — sold's
-1 the same day is selling at 0 after buying at 3, correctly terrible.
