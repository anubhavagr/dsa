## 🔥 Pattern of the Day: LIFO = the most recent unmatched thing
A stack is the answer whenever the object you need next is the one you saw most recently and have not yet resolved: the last opened bracket, the last operand waiting for an operator.
Matching problems become a loop of "push openers, verify closers against the top" — and emptiness at the end is half the correctness claim, so test it deliberately.
When a stack must answer aggregate queries (min), stop storing bare values: store (value, aggregate-so-far) pairs and every query becomes O(1).
Reach for a stack on nesting, matching, undo-style reversal, and deferred evaluation.
Invariant (matching): every element below the top is still waiting for a partner the future must supply.

```python
def valid_parentheses(s):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in pairs:                 # a closer: it must match the latest opener
            if not stack or stack.pop() != pairs[ch]:
                return False            # nothing open, or wrong kind open
        else:
            stack.append(ch)            # an opener: park it, work continues
    return not stack                    # everything that opened has closed

def eval_rpn(tokens):
    ops = {'+': lambda a, b: a + b, '-': lambda a, b: a - b,
           '*': lambda a, b: a * b, '/': lambda a, b: int(a / b)}
    stack = []
    for t in tokens:
        if t in ops:
            b = stack.pop()             # operand order: second pop is LEFT
            a = stack.pop()
            stack.append(ops[t](a, b))
        else:
            stack.append(int(t))
    return stack[0]

class MinStack:                         # carry the running min alongside
    def __init__(self):
        self.stack = []
    def push(self, val):
        m = min(val, self.stack[-1][1]) if self.stack else val
        self.stack.append((val, m))     # pair: value + min of everything below
    def pop(self):
        self.stack.pop()                # aggregate leaves WITH its element
    def top(self):
        return self.stack[-1][0]
    def getMin(self):
        return self.stack[-1][1]        # O(1), no scan, ever
```

Watch-outs:
- The two failure modes of matching: closer with nothing open, and openers left over — write a test for each before submitting.
- RPN operand order bites on `-` and `/`: the second value popped is the left operand.
- `int(a / b)` (truncate toward zero) is not `a // b` (floors) for negatives — LeetCode's RPN expects truncation; say why out loud.
