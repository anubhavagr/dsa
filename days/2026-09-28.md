## 🔥 Pattern of the Day: Canonical keys + counting
Two objects belong to the same group exactly when some cheap function maps them to the same key — find that function and a dict does the grouping for you.
For anagrams the canonical key is the sorted string (or a 26-tuple of counts); for "seen before?" the key is the value itself; for frequency questions the count map IS the answer waiting to be selected from.
Reach for this whenever a problem says group, classify, duplicate, or count.
Invariant: after processing element i, the dict is a complete summary of the prefix — the raw elements before i are never needed again.
When the quantity you select on (a frequency) is bounded by n, bucket arrays replace sorting entirely.

```python
def group_anagrams_brute(strs):        # O(n^2 * k): compare every pair
    used = [False] * len(strs)
    groups = []
    for i, s in enumerate(strs):
        if used[i]:
            continue
        group, used[i] = [s], True
        for j in range(i + 1, len(strs)):
            if not used[j] and sorted(strs[j]) == sorted(s):
                used[j] = True
                group.append(strs[j])
        groups.append(group)
    return groups
```

```python
from collections import Counter, defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = ''.join(sorted(s))        # canonical form: anagrams collide here
        groups[key].append(s)           # grouping == dict keyed by a stable id
    return list(groups.values())

def top_k_frequent(nums, k):
    count = Counter(nums)               # one O(n) pass builds the frequency map
    buckets = [[] for _ in range(len(nums) + 1)]   # bucket index = a frequency
    for val, c in count.items():
        buckets[c].append(val)
    out = []
    for c in range(len(buckets) - 1, 0, -1):       # walk counts high -> low
        for val in buckets[c]:
            out.append(val)
            if len(out) == k:
                return out              # no sort anywhere: O(n), not O(n log k)
```

Watch-outs:
- Sorting each string keys the map in O(n · k log k); the count-tuple key is O(n · k) — state both numbers, then pick.
- `Counter.most_common(k)` is the heap one-liner (O(n log k)) — legal, but say its cost before you use it.
