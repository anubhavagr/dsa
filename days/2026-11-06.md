## 🔥 Pattern of the Day: Composite Structures for O(1) Ops
Design questions are about pairing structures so each operation stays O(1): a dict gives key lookup but no order; a doubly-linked list gives order but no lookup — together they are an LRU.
The same move powers GetRandom: a list gives random indexing but O(n) delete, so a dict maps each key to its slot and deletion swaps the victim to the end first. State the invariant *before* coding — for the LRU: `head.next` is most recent, `tail.prev` is least.

- **Reach for it when:** a problem says "design a structure" and states a per-operation complexity requirement — the intended answer is almost always pairing two standard structures so every operation stays within the bound.
- **Key invariant:** The hash map and the linked list describe exactly the same set of entries at every moment — a node removed from the list must have its key removed from the map in the same operation, and vice versa.
- **Watch out:** In an LRU cache every read is also a write — a get must move the accessed node to the most-recent position, so forgetting to update recency on reads makes the cache evict the wrong entry.
- **How to say it in an interview:** "I pair two structures so each covers the other's weakness: a hash map gives O(1) lookup but no order, a doubly-linked list gives O(1) reordering but no lookup, and pointing map entries at list nodes makes every operation constant time. For GetRandom the same move applies — a list gives random indexing but O(n) delete, so a dict maps each key to its slot and deletion swaps the victim to the end first."
- **Test with:** capacity 1 (every insert evicts the previous entry) · an insert that overwrites an existing key (must update in place, not create a duplicate) · a get on a missing key (must return the default and change nothing).
- **Complexity:** Every operation is O(1) — one hash-map lookup plus a constant number of linked-list pointer splices — and the price is the extra memory for the second structure.

```python
class LRUCache:                           # dict: O(1) lookup · DLL: O(1) recency
    def __init__(self, cap):              # Node has {k, v, prev, next}
        self.cap, self.map = cap, {}
        self.h, self.t = Node(), Node()   # sentinels: h.next = MRU, t.prev = LRU
        self.h.next, self.t.prev = self.t, self.h

    def _front(self, n):                  # every touch splices n after head
        if n.next: n.prev.next, n.next.prev = n.next, n.prev
        n.prev, n.next = self.h, self.h.next
        self.h.next.prev = n; self.h.next = n

    def get(self, key):
        n = self.map.get(key)
        if n is None: return -1
        self._front(n); return n.v        # recency restored

    def put(self, key, v):
        if key in self.map:
            self.map[key].v = v; return self._front(self.map[key])
        n = self.map[key] = Node(key, v); self._front(n)
        if len(self.map) > self.cap:      # evict the tail — t.prev is the LRU
            lru = self.t.prev
            lru.prev.next, lru.next.prev = self.t, lru.prev
            del self.map[lru.k]
```
