## 🔥 Pattern of the Day: The Rolling Row
Grid DP is one pass in dependency order — top-left to bottom-right — where each cell reads only "up" and "left".
Because those two live in adjacent positions of the previous and current row, a full 2-D table collapses to a single row updated left to right: before the write, `row[c]` still holds "from above", and `row[c-1]` already holds "from left". Maximal square is the same pass with a different gate: the cell stores a side length, allowed to be one more than the minimum of its three neighbors (up, left, diagonal).

- **Reach for it when:** you walk a grid and each cell's answer comes from predecessors (paths, sums, squares, blocks).
- **Key invariant:** during the row pass, row[c] = above (old) and row[c-1] = left (new).
- **Watch out:** obstacles in unique-paths-style problems zero a cell *before* it propagates.
- **Interview soundbite:** "Mid-pass, row[c] is 'above' and row[c-1] is 'left'."
- **Test out loud:** a 1xN grid · a single cell · all-equal values.
- **Cost:** O(m·n) time with an O(n) rolling row — the full 2-D table is never needed.

```python
def unique_paths(m, n):                   # roll one row top to bottom
    row = [1] * n                         # first row: 1 way everywhere
    for _ in range(1, m):
        for c in range(1, n):
            row[c] += row[c - 1]          # above (old row[c]) + left
    return row[-1]

def min_path_sum(grid):
    n = len(grid[0])
    row = [float('inf')] * (n + 1)        # +inf guard column on the left
    row[1] = 0                            # seeds cell (0, 0) naturally
    for r in range(len(grid)):
        for c in range(n):
            row[c + 1] = min(row[c], row[c + 1]) + grid[r][c]
    return row[n]

def maximal_square(g):                    # LC 221: gate = min of three + 1
    best, diag, row = 0, 0, [0] * (len(g[0]) + 1)
    for r in range(len(g)):
        for c in range(1, len(row)):      # row[c] is 'above' until overwritten
            row[c], diag = (min(row[c], row[c - 1], diag) + 1
                            if g[r][c - 1] == '1' else 0), row[c]
            best = max(best, row[c])
    return best * best
```
