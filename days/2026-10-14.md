## 🔥 Pattern of the Day: Weave copies between the originals
The random-pointer copy fails naively because a copy's `random` must point at ANOTHER COPY that may not exist yet.
The fix: interleave — after copying node A, park A' directly after it, so every original X has its copy X' at X.next.
Then random pointers resolve in one pass (X.random.next is X.random's copy), and a final pass unweaves two clean lists.
Reach for weaving whenever nodes must reference each other but are built one at a time.
Invariant: after pass 1, positions 1, 3, 5... are originals and 2, 4, 6... are their copies — adjacency encodes the mapping, no dict needed.
Complexity to narrate: three passes, O(n) time, O(1) extra space beyond the output — versus the dict version's O(n) auxiliary; both beat re-scanning for random targets.
The dict-first-then-weave ladder IS the interview: state the simple version, name its cost, then present the upgrade with its invariant — that sequence reads as senior.
For Sort List, say why merge sort: split via the middle finder in O(n), merge via Monday's primitive, recurse O(log n) deep — no random access anywhere in the argument.
Random-pointer bugs are aliasing bugs — when a test fails, print node addresses (id()), not values.

```python
class Node:
    def __init__(self, val=0, next=None, random=None):
        self.val, self.next, self.random = val, next, random

def copy_random_list(head):
    if not head:
        return None
    cur = head
    while cur:                          # pass 1: weave — A A' B B' C C' ...
        cur.next = Node(cur.val, cur.next)
        cur = cur.next.next
    cur = head
    while cur:                          # pass 2: aim each copy's random
        if cur.random:
            cur.next.random = cur.random.next   # original's random -> its copy
        cur = cur.next.next
    cur = head
    dummy = tail = Node(0)
    while cur:                          # pass 3: unweave into two lists
        tail.next = cur.next            # harvest the copy
        tail = tail.next
        cur.next = cur.next.next        # restore the original's link
        cur = cur.next
    return dummy.next                   # original list exactly restored
```

Watch-outs:
- The dict-based copy (original -> copy map) is equally valid and easier to see — offer it first, then present weaving as the O(1)-extra-space upgrade. Interviewers love that ladder.
- Sort List: name the sort before you code — merge sort, because quicksort's random access is exactly what a list lacks; base case is `None` or a single node.
- k-group reversal: count k first; if fewer than k remain, leave the tail untouched — that guard is the difference between accepted and mangled.
- Test the copy against the original after unweaving — the ORIGINAL list must survive intact, or the judge (and the interviewer) will notice.
