## 🔥 Pattern of the Day: Make the locally best move, prove it sticks
A greedy algorithm makes one irrevocable choice per step — no backtracking, no table — so its correctness lives in an argument, not in search: the exchange argument ("swap any optimal solution's first choice for mine and it cannot get worse").
For interval scheduling that argument lands on earliest-end-first: finishing earlier removes no future option that a later finisher would have kept.
Other greedies need no sort at all — just one running quantity (farthest reachable index, fuel surplus) updated as you scan.
The interview move is stating WHY the greedy is safe before writing it; a greedy without its proof is a guess.
Invariant (reach): every index ≤ reach is reachable, and nothing beyond it is — reach only ever grows.
Complexity to narrate: the reach greedy is one O(n) pass with O(1) space; the interval greedy pays O(n log n) for the sort and O(n) for the sweep — the sort IS the algorithm, the sweep is trivial.
Greedy versus DP, the line to deliver: greedy commits, DP hedges — if a wrong early choice can be rescued later, you need DP; if the exchange argument holds, greedy is optimal and cheaper.
Gas Station's one-pass shape: run a cumulative surplus; wherever it dips negative, restart the candidate at the NEXT station — the answer is the last candidate standing, if total surplus ≥ 0.
Partition Labels is a reach problem in costume: each letter's last occurrence is a launchpad, and a chunk closes when the scan catches up to the maximum frontier of everything inside it.
Test greedies by adversarial construction: build the smallest input where your rule and the optimal rule first disagree — if you cannot construct one, that failure IS the proof sketch.
State the one-sentence safety argument before ANY greedy code — an unjustified greedy reads as a guess, and interviewers grade it as one.

```python
def can_jump(nums):
    reach = 0                        # farthest index known reachable so far
    # invariant: [0, reach] is exactly the reachable prefix so far
    for i, x in enumerate(nums):
        if i > reach:                # a gap: i itself was never reachable
            return False
        reach = max(reach, i + x)    # greedily extend with today's launchpad
    return True                      # the scan survived: n-1 stayed in reach

def max_meetings(intervals):         # the canonical exchange-argument greedy
    intervals.sort(key=lambda iv: iv[1])   # earliest END first — the safe order
    taken, free_at = 0, float('-inf')
    for start, end in intervals:
        if start >= free_at:         # compatible with everything chosen
            taken += 1
            free_at = end            # my end becomes the next constraint
            # earliest finish keeps the most future room — the exchange
    return taken                     # optimality lives in the sort key, not here
```

Watch-outs:
- Greedy fails silently where DP succeeds — if you cannot sketch the exchange argument in one sentence, suspect the greedy and reach for the search/DP framing instead.
- Interval corner: touching intervals ([1,3] and [3,5]) — decide inclusive versus exclusive from the statement, then test exactly that boundary.
- Jump Game on [0] is trivially true — a single-element array is reachable by doing nothing; free edge-case credit in the room.
- If you cannot justify the greedy mid-interview, say so and pivot aloud to small cases or a DP framing — that honesty scores better than confident hand-waving.
- Partition Labels with "aaaa" versus "abcd" makes the frontier logic visible — run both by hand once.
- Sorting by START (not end) is the classic wrong move for scheduling: a short meeting ending early beats an early-starting marathon — be ready to say why with a two-meeting example.
- Gas station's key lemma: if you cannot reach station j from station i, no station between them works either — the restart jumps past the whole span.
