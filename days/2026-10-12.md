## 🔥 Pattern of the Day: Rewire in place, one arrow at a time
A linked list gives you no indexing and no back-pointers — only `.next` — so every technique is a choreography of a few pointer variables.
Reversal is the purest example: save the only forward pointer you are about to destroy, flip one arrow, advance both walkers — the loop body never changes, only who the walkers are.
A dummy head absorbs every "but what if it's the first node" branch, which is where most list bugs live; build one the moment a problem might delete or insert at the head.
Invariant (reversal): `prev` points at an already-reversed prefix, `cur` at an untouched suffix — the seam between them is the only place work happens.

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val, self.next = val, next

def reverse_rebuild(head):            # O(n) extra memory — say the cost aloud
    vals = []
    node = head
    while node:
        vals.append(node.val)
        node = node.next
    node = head
    for v in reversed(vals):          # scribble values back over the same nodes
        node.val = v
        node = node.next
    return head
```

```python
def reverse_list(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next          # save the only forward pointer you're destroying
        cur.next = prev         # flip exactly one arrow this iteration
        prev, cur = cur, nxt    # both walkers advance one node
    return prev                 # prev lands on the old tail — the new head

def merge_two(a, b):
    dummy = tail = ListNode()   # dummy: the head stops being a special case
    while a and b:
        if a.val <= b.val:
            tail.next, a = a, a.next
        else:
            tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b          # non-empty remainder bolts on whole
    return dummy.next
```

Watch-outs:
- Draw the three boxes (prev, cur, nxt) before coding — in interviews, the diagram IS the bug detector.
- `while cur` (not `while cur.next`) — you process every node, and the loop ends with prev on the new head.
- Walk your code on a 0-node and 1-node list every single time; those two cases catch most list bugs for free.
